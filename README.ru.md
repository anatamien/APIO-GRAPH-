# APIO GRAPH 1.0.0

Настольный редактор научных графиков: импорт данных, математическая обработка, оформление и экспорт. Работа локальная, без регистрации и облачного сервера.

## Возможности

- TXT/CSV/TSV, вставка таблицы и ручной ввод. Независимые графики во вкладках и явное добавление к текущему графику.
- Оси, линии, точки и легенда; текст с индексами, стрелки, выноски и области.
- Регрессии, Савицкий — Голей, скользящее среднее, производная, интеграл, интерполяция и статистика. Исходные измерения сохраняются отдельно от результатов.
- Панорамирование, масштабирование колёсиком и F9. Оптимизация экрана сохраняет исходные данные для вычислений и экспорта.
- SVG/PNG/JPEG с управлением размером, DPI и цветами, включая строгий чёрно-белый режим.
- Полные проекты `.aph`, история изменений и восстановление работы.
- RU/EN, светлая, True Black и системная темы.

## Установка

На странице **Releases** скачайте `APIO-GRAPH-1.0.0-windows-x64-offline-setup.exe`. Установщик предложит русский или английский язык, установит приложение для текущего пользователя, добавит ярлык в меню «Пуск» и привязку `.aph`.

Microsoft WebView2 включён в установщик. Отдельно скачивать WebView2, Node.js, Rust или инструменты разработки не нужно; первоначальная установка поддерживает работу без интернета. Целевая платформа — Windows 10/11 x64. Это не сборка для Windows 7, ARM64 или macOS. Корпоративные ограничения могут запрещать установку приложений.

Первая сборка **без цифровой подписи Authenticode**: Windows может показать предупреждение о неизвестном издателе или SmartScreen. Контрольная сумма `SHA256SUMS.txt` в релизе проверяет целостность файла и не заменяет подпись издателя.
